# Mic Manager design

The app has one look, in `src/renderer/styles.css`: dark, following Apple's interface guidelines for clarity, deference and depth.

## Behaviour
- The EQ opens like a dropdown. It's closed by default and the choice is remembered, with its on/off switch and preset always in reach.
- A plain mouse wheel over the graph scrolls the page. Ctrl + scroll changes a band's width.

## History
The git tag `before-glass-look` marks the last commit before the Glass and Dark looks were added. Both were later removed.
